## 1. 第一次開啟

1. 開啟 3mfDeck（macOS 第一次會被 Gatekeeper 擋下，處理方式見 README）。
2. 到 **設定**（右上齒輪）確認三件事：
   - **噴嘴尺寸**：你的 U1 目前裝的噴嘴（預設 0.4 mm）。匯出時會依這個設定選 Orca 設定檔。
   - **檔案櫃根目錄**：預設 `~/3mf-library/`。想放在 iCloud Drive 或外接硬碟，可在這裡改（見[第 13 節](#13-設定頁)）。
   - **耗材捲色**：U1 上實際裝的線材顏色（預設理想 CMYK）。顏色分析、混色配方、匯出都用這組顏色計算。
3. 匯出別台印表機的專案、以及「公仔」設定，需要本機安裝 **Snapmaker Orca**（`/Applications/Snapmaker Orca.app`），App 只讀它的設定檔，不連網。

![設定頁的噴嘴尺寸](screenshots/zh-TW/7-settings-nozzle.png)

## 2. 畫面導覽

| 區域 | 內容 |
|---|---|
| 左側欄 | 過濾器：全部、未標（來源未填）、非 U1、重複、來源類型（AI 生成／下載／自繪）、平台（MakerWorld…）、遺失、回收桶；顏色（可多選）、標籤；最下方「採購建議…」與版本號 |
| 上方工具列 | 搜尋、排序（匯入日期／名稱／色數）、卡片牆／清單切換、「匯入…」、設定 |
| 中央 | 卡片牆或清單。卡片上的徽章：來源、色數、盤數、非 U1、重複組、遺失 |
| 右側詳情面板 | 點卡片後出現：3D 預覽、匯出、顏色分析、來源與備註、檔案資訊 |

## 3. 匯入檔案

三種方式：拖放檔案或資料夾到視窗、按 **匯入…**、或選單 **檔案 › 匯入…**。支援 `.3mf .stl .obj .amf .glb .gltf .step .stp`。

- **檔案會被搬進檔案櫃**（`<根目錄>/<年份>/<檔名>`），不是複製。同名但內容不同時自動加 `-2`、`-3`，不會覆蓋。
- **內容完全相同的檔案不會再匯入**：即使檔名、資料夾不同，只要內容一模一樣就略過，原檔留在原處不動，並提示已存在的那一份（可按「檢視」跳過去）。若相同的檔案在回收桶裡，提示會引導你到回收桶還原。
- 匯入後會跳出**匯入對話框**，逐檔填來源：來源類型（AI 生成／下載／自繪）、平台、網址、AI prompt、取得日期、標籤（逗號分隔）、備註。
  - MakerWorld／Bambu Studio 的 3MF 會**自動預填**來源（設計師、授權、平台），通常只要按「儲存並下一個」。
  - 不想現在填可按「略過此檔」或「全部略過」；之後左側「未標」會列出這些檔案，提醒你補上。

## 4. 整理與尋找

- **搜尋**：名稱、標籤、備註，以及**色名**（例：輸入「紅」找含紅色的模型；用英文或簡中搜尋也找得到）。
- **顏色過濾**：左側「顏色」點色名，只列出該色佔面積 5% 以上的檔案；選多個色名時，要同時含有才會列出。
- **編輯**：在詳情面板「來源與備註」隨時修改名稱、來源、標籤、備註。
- **在 Finder 顯示**：詳情面板右上的資料夾圖示。
- **刪除**：詳情面板右上的垃圾桶圖示，檔案移到回收桶，可還原（見[第 12 節](#12-重複遺失與回收桶)）。

## 5. 看模型：3D 預覽與原檔圖

- 詳情面板上方是 3D 預覽，可拖曳旋轉、滾輪縮放。著色模式：
  - **原始**：檔案本身的顏色。
  - **耗材映射**：每個顏色換成實際會用的捲色（單捲或混色），也就是匯出後的樣子。
  - **混色估計**：Full Spectrum 抖色檔才有，模擬遠看的混色效果（估計值，以 Orca 為準）。
- **原檔圖**：MakerWorld 專案內嵌的封面、創作者實拍、Orca 盤面圖，可切換瀏覽。卡片縮圖也會優先用封面。
- **多盤 3MF**：每盤可分開檢視與分析。
- STEP 檔暫不支援預覽（仍可收進櫃子）。

## 6. 顏色分析：這件作品印得出來嗎

詳情面板的「顏色分析」卡片（3MF 才有）：

- **面積比例條**：各顏色佔模型表面積的比例。
- **列印方式欄**：每個顏色怎麼印——
  - **槽 N 單捲**：某一捲就夠接近（ΔE 小）。
  - **混色**：兩捲以 Orca 的 Full Spectrum 混合耗材（Mix）混出，附配方與 ΔE。
  - **需買線材**：手上捲色怎麼混都差太多。會寫「不買則用某槽（ΔE）」，告訴你不買的話實際會印成什麼。
- **可印／不可印比例**：例如「可印 97.66%、不可印 2.34%」。不會只給好看的數字。
- **疑似抖色**：兩個非常接近的顏色可能是同一塊被抖色拆開，會特別標出。
- **超過 4 色**時會提示需要 Full Spectrum 混色。

## 7. 決定要裝哪幾捲線材

在顏色分析按 **建議捲色…**：

- **理想建議**：依模型顏色算出的最佳 1–4 捲色碼（需要採購時對照色卡選最近色）。
- **從我的線材挑**：從線材庫（[第 8 節](#8-線材庫與採購建議)）列舉所有組合，挑最少捲數又能把所有顏色印出來的一組，包括「兩捲混出第三色」的情況。
- **標準配置**：CMYK、CMYW 的覆蓋率對照。
- 每個方案都顯示「單捲直印／含混色／不可印」比例。佔比達 0.1% 以上的顏色都印得出才會被標為「建議」，小細節（眼睛、鼻子）不會被主色平均掉。
- 按 **套用到捲色設定**，耗材映射、混色配方與匯出就改用這組捲色。

## 8. 線材庫與採購建議

- **線材庫**（設定頁）：登記你擁有的線材（名稱、色碼）。也可以從 [3dfilamentprofiles.com 的 My Spools](https://3dfilamentprofiles.com/my/spools) 匯出 JSON／CSV 後，按「從 3dfilamentprofiles 匯入…」一次匯入，確認後按「儲存線材庫」。
- **採購建議**（左側欄最下方）：統計整個檔案櫃的顏色排行（每個有顏色的模型權重相同），對照線材庫列出缺的顏色、建議優先購買哪些；可直接「加入線材庫」。

## 9. 匯出 3MF 到 Snapmaker Orca

詳情面板標題列右邊：

1. 從**列印設定**下拉選：
   - **原檔設定**：一般列印。
   - **公仔**／**公仔＋熨燙**：見[第 10 節](#10-公仔設定)。
2. 按 **匯出 3MF…**，選存檔位置。

匯出內容：

- 每個顏色量化到捲色；單捲印不出的寫成 Orca 原生的**混合耗材（Mix）**，在 Orca 開啟即配好色。
- 剝除來源的切片設定，只留幾何、顏色、捲色表與 U1 設定名稱，避免 Orca 跳相容性警告。
- 機型與 process 依設定頁的**噴嘴尺寸**選擇。
- 一律存成 **Snapmaker U1 專案**：Exclude Object 開、Brim 關（公仔例外）；別台印表機的專案會一併換到 U1 盤面（見[第 11 節](#11-別台印表機的檔案匯出即轉-u1)）。
- **原檔永遠不會被修改**，匯出一律是新檔。

## 10. 公仔設定

依 r/PrintedMinis〈[FDM miniatures - How I support them and some updates](https://www.reddit.com/r/PrintedMinis/comments/1i8hcyz/fdm_miniatures_how_i_support_them_and_some_updates/)〉（u/HOHansen）的原則，換算到你的噴嘴。匯出時選「公仔」會寫入：

| 項目 | 值 |
|---|---|
| 層高 | 該噴嘴最低層高（0.2→0.04、0.4→0.08、0.6→0.12、0.8→0.16 mm） |
| 第一層 | 0.2 mm（讓支撐與裙邊黏牢） |
| 支撐 | 開啟、樹狀（Tree Hybrid 樣式），支撐上方 Z 距離＝層高，不用介面層，支撐內部填充（rectilinear、間距 1.2 mm） |
| 裙邊 | 僅外側、10 mm（蓋住支撐底部） |
| 牆 | Arachne，最小特徵 30% |
| 內部填充 | 閃電（Lightning）：只在需要撐住上方表面的地方填充，內部大多空心（實測熊：22 小時 12 分 → 約 16 小時） |
| 線寬 | 0.2 噴嘴改 0.2，其他噴嘴沿用 U1 預設 |
| 冷卻 | 風扇 100%，第一層除外 |
| 回抽抬升 | U1 預設已開啟，不另外改 |

**公仔＋熨燙**：再加熨燙「所有朝上的平面」（例如平的底座頂部），熨燙間距為噴嘴的 25%（0.4 噴嘴＝0.1 mm）。公仔身上朝上的小平台也會被燙到，請在切片預覽確認細節。

**一定要自己做的事**（檔案無法設定）：在 Orca 把模型**往後傾 20–45°**（需要時再往左或右 20°），減少懸空面，支撐痕跡會少很多。

> **為什麼是 Tree Hybrid**：原貼文的重點之一是在樹狀支撐**內部加填充**，避免支撐中途斷掉。U1 預設的樹狀樣式是 Organic，Organic 的樹幹一律空心、會忽略填充設定；改成 Tree Hybrid 才會填充（實測同一隻熊：Organic 每根支撐只有一圈外殼，Tree Hybrid 內部有間距 1.2 mm 的填充線）。代價是用料約多 3%、列印時間約多 2%；大片平坦的懸空面底下會改用一般支撐，那裡比較難拆。

## 11. 別台印表機的檔案（匯出即轉 U1）

別人分享的 3MF 常是 Bambu Lab 等其他機型的專案，直接開會沿用原機型盤面，物件可能超出 U1。

- 這類檔案的卡片與詳情面板會出現 **非 U1** 警示（含原機型），左側「非 U1」可列出全部。
- 不需要另外轉換：照[第 9 節](#9-匯出-3mf-到-snapmaker-orca)按 **匯出 3MF…**，匯出的檔案就是 U1 專案，原檔不動。匯出時會：
  - 機型、process、線材改用 U1 設定，**依設定頁的噴嘴尺寸**選擇（不看原檔的噴嘴）。
  - 多盤物件搬到 U1 盤面座標；無法安全換算的盤保持原位，匯出訊息會說明原因。
  - 帶入原檔改過的部分設定（例如支撐、填充密度）與線材設定（溫度、流速、冷卻）。每個捲槽採用「映射到它面積最多的那條原檔線材」的設定；和列印設定（公仔等）衝突時以列印設定為準。
- 很大的專案（模型資料超過 1 GB）也能匯出，只是比較久。

## 12. 重複、遺失與回收桶

- **重複**（左側欄）：列出檔案櫃中內容完全相同的檔案，依組顯示「重複組 N」徽章。由你決定刪哪一個，App 不會自動刪除。舊檔案的指紋在啟動後於背景建立；尚未下載到本機的 iCloud 檔案會先略過，下載後才比對。
- **遺失**：記錄還在、但目前根目錄找不到檔案（例如換了根目錄或手動搬走）。
  - 單筆：詳情面板「重新定位…」指到檔案現在的位置。
  - 多筆：「依檔名找回…」在根目錄（含子資料夾）找同名檔案，確認後一次套用，不搬檔。
  - 不要了：勾選後「移除所選…」只移除記錄，不刪任何檔案。
- **回收桶**：刪除的檔案在 `<根目錄>/.trash/`，可逐一「還原」回原位；「清空回收桶…」需二次確認後才真的刪除。
- **重建索引**：若有檔案在檔案櫃資料夾裡卻不在索引中（例如手動放入），上方會提示，按「重建索引」即可收錄。

## 13. 設定頁

| 項目 | 說明 |
|---|---|
| 噴嘴尺寸 | 0.2／0.4／0.6／0.8 mm，影響匯出的設定檔 |
| 語言 | English／繁體中文／简体中文，預設跟隨系統 |
| 檔案櫃根目錄 | 變更時**不搬任何檔案**，只對新根目錄重建索引；舊根目錄的記錄標為「遺失」，切回即恢復 |
| 耗材捲色 | 1–4 捲的實際色碼；「恢復理想 CMYK」回到預設 |
| 線材庫 | 見[第 8 節](#8-線材庫與採購建議) |
| 版本與更新 | 目前版本、開啟 Releases 頁面、自動檢查更新開關 |

**更新**：預設在背景每 24 小時最多查一次 GitHub 上的最新版，有新版時在側欄提示（前往下載／略過此版本／關閉）。這是 App 唯一的網路行為，可在這裡關閉。更新一律手動下載安裝。

## 14. 常見問題

**匯出的檔案在 Orca 開啟後，公仔設定沒有生效？**
請確認用的是新版 3mfDeck（1.2610.110033 以後）。舊版寫入的設定會被 Orca 忽略。

**為什麼匯入時某個檔案沒有被收進來？**
看提示：內容和櫃中某個檔案完全相同時會略過（原檔留在原處）；不支援的格式也會略過。

**「需買線材」的顏色一定要買嗎？**
不一定。旁邊會寫「不買則用某槽（ΔE）」，你可以接受色差直接印。

**換了根目錄，所有檔案都變成「遺失」？**
換根目錄不會搬檔，原根目錄下的記錄會標為遺失。切回原根目錄即恢復；或用「依檔名找回…」對應到新位置。

**匯出時說找不到 Snapmaker Orca？**
這兩個功能需要讀本機 Snapmaker Orca 的設定檔，請先安裝 Snapmaker Orca。
