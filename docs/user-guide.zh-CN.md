## 1. 第一次打开

1. 打开 3mfDeck（macOS 第一次会被 Gatekeeper 拦下，处理方式见 README）。
2. 到 **设置**（右上齿轮）确认三件事：
   - **喷嘴尺寸**：你的 U1 目前装的喷嘴（默认 0.4 mm）。转换 U1 与导出都会按这个设置选 Orca 预设。
   - **模型库根目录**：默认 `~/3mf-library/`。想放在 iCloud Drive 或外接硬盘，可在这里改（见[第 13 节](#13-设置页)）。
   - **料卷颜色**：U1 上实际装的耗材颜色（默认理想 CMYK）。颜色分析、混色配方、导出都用这组颜色计算。
3. “转换为 Snapmaker U1”与“手办”设置需要本机安装 **Snapmaker Orca**（`/Applications/Snapmaker Orca.app`），App 只读取它的预设文件，不联网。

## 2. 界面导览

| 区域 | 内容 |
|---|---|
| 左侧栏 | 过滤器：全部、未标（来源未填）、非 U1、重复、来源（AI 生成／下载／自绘）、平台（MakerWorld…）、丢失、回收站；颜色（可多选）、标签；最下方“采购建议…”与版本号 |
| 上方工具栏 | 搜索、排序（导入日期／名称／色数）、卡片墙／列表切换、“导入…”、设置 |
| 中央 | 卡片墙或列表。卡片上的徽章：来源、色数、盘数、非 U1、重复组、丢失 |
| 右侧详情面板 | 点击卡片后出现：3D 预览、导出、颜色分析、来源与备注、文件信息 |

## 3. 导入文件

三种方式：把文件或文件夹拖到窗口、点 **导入…**、或菜单 **文件 › 导入…**。支持 `.3mf .stl .obj .amf .glb .gltf .step .stp`。

- **文件会被移进模型库**（`<根目录>/<年份>/<文件名>`），不是复制。同名但内容不同时自动加 `-2`、`-3`，不会覆盖。
- **内容完全相同的文件不会再导入**：即使文件名、文件夹不同，只要内容一模一样就跳过，原文件留在原处不动，并提示已存在的那一份（可点“查看”跳过去）。如果相同的文件在回收站里，提示会引导你到回收站还原。
- 导入后会弹出**导入对话框**，逐个文件填来源：来源类型（AI 生成／下载／自绘）、平台、网址、AI prompt、获取日期、标签（逗号分隔）、备注。
  - MakerWorld／Bambu Studio 的 3MF 会**自动预填**来源（设计师、授权、平台），通常只要点“保存并下一个”。
  - 不想现在填可点“跳过此文件”或“全部跳过”；之后左侧“未标”会列出这些文件，提醒你补上。

## 4. 整理与查找

- **搜索**：名称、标签、备注，以及**色名**（例：输入“红”找含红色的模型；用英文或繁中搜索也找得到）。
- **颜色过滤**：左侧“颜色”点色名，只列出该色占面积 5% 以上的文件；选多个色名时，要同时含有才会列出。
- **编辑**：在详情面板“来源与备注”随时修改名称、来源、标签、备注。
- **在访达中显示**：详情面板右上的文件夹图标。
- **删除**：详情面板右上的垃圾桶图标，文件移到回收站，可还原（见[第 12 节](#12-重复丢失与回收站)）。

## 5. 看模型：3D 预览与原文件图

- 详情面板上方是 3D 预览，可拖动旋转、滚轮缩放。着色模式：
  - **原始**：文件本身的颜色。
  - **耗材映射**：每个颜色换成实际会用的料卷颜色（单卷或混色），也就是导出后的样子。
  - **混色估计**：Full Spectrum 抖色文件才有，模拟远看的混色效果（估计值，以 Orca 为准）。
- **原文件图**：MakerWorld 项目内嵌的封面、创作者实拍、Orca 盘面图，可切换浏览。卡片缩略图也会优先用封面。
- **多盘 3MF**：每盘可分开查看与分析。
- STEP 文件暂不支持预览（仍可收进模型库）。

## 6. 颜色分析：这件作品打印得出来吗

详情面板的“颜色分析”卡片（3MF 才有）：

- **面积比例条**：各颜色占模型表面积的比例。
- **打印方式栏**：每个颜色怎么打印——
  - **槽 N 单卷**：某一卷就够接近（ΔE 小）。
  - **混色**：两卷以 Orca 的 Full Spectrum 混合耗材（Mix）混出，附配方与 ΔE。
  - **需买耗材**：手上料卷怎么混都差太多。会写“不买则用某槽（ΔE）”，告诉你不买的话实际会打印成什么。
- **可打印／不可打印比例**：例如“可打印 97.66%、不可打印 2.34%”。不会只给好看的数字。
- **抖色？**：两个非常接近的颜色可能是同一块被抖色拆开，会特别标出。
- **超过 4 色**时会提示需要 Full Spectrum 混色。

## 7. 决定要装哪几卷耗材

在颜色分析点 **建议料卷颜色…**：

- **理想建议**：按模型颜色算出的最佳 1–4 卷色号（需要采购时对照色卡选最近色）。
- **从我的耗材挑**：从耗材库（[第 8 节](#8-耗材库与采购建议)）列举所有组合，挑最少卷数又能把所有颜色打印出来的一组，包括“两卷混出第三色”的情况。
- **标准配置**：CMYK、CMYW 的覆盖率对照。
- 每个方案都显示“单卷直印／含混色／不可打印”比例。占比达 0.1% 以上的颜色都打印得出才会被标为“建议”，小细节（眼睛、鼻子）不会被主色平均掉。
- 点 **应用到料卷设置**，耗材映射、混色配方与导出就改用这组料卷颜色。

## 8. 耗材库与采购建议

- **耗材库**（设置页）：登记你拥有的耗材（名称、色号）。也可以从 [3dfilamentprofiles.com 的 My Spools](https://3dfilamentprofiles.com/my/spools) 导出 JSON／CSV 后，点“从 3dfilamentprofiles 导入…”一次导入，确认后点“保存耗材库”。
- **采购建议**（左侧栏最下方）：统计整个模型库的颜色排行（每个有颜色的模型权重相同），对照耗材库列出缺的颜色、建议优先购买哪些；可直接“加入耗材库”。

## 9. 导出 3MF 到 Snapmaker Orca

详情面板标题栏右边：

1. 从**打印设置**下拉选：
   - **原文件设置**：一般打印。
   - **手办**／**手办＋熨烫**：见[第 10 节](#10-手办设置)。
2. 点 **导出 3MF…**，选保存位置。

导出内容：

- 每个颜色量化到料卷颜色；单卷打印不出的写成 Orca 原生的**混合耗材（Mix）**，在 Orca 打开即配好色。
- 剥除来源的切片设置，只留几何、颜色、料卷颜色表与 U1 预设名称，避免 Orca 弹出兼容性警告。
- 机型与 process 按设置页的**喷嘴尺寸**选择。
- **原文件永远不会被修改**，导出一律是新文件。

## 10. 手办设置

依 r/PrintedMinis〈[FDM miniatures - How I support them and some updates](https://www.reddit.com/r/PrintedMinis/comments/1i8hcyz/fdm_miniatures_how_i_support_them_and_some_updates/)〉（u/HOHansen）的原则，换算到你的喷嘴。导出时选“手办”会写入：

| 项目 | 值 |
|---|---|
| 层高 | 该喷嘴最低层高（0.2→0.04、0.4→0.08、0.6→0.12、0.8→0.16 mm） |
| 首层 | 0.2 mm（让支撑与裙边粘牢） |
| 支撑 | 开启、树状（Tree Hybrid 样式），支撑顶部 Z 距离＝层高，不用接触层，支撑内部填充（rectilinear、间距 1.2 mm） |
| 裙边 | 仅外侧、10 mm（盖住支撑底部） |
| 墙 | Arachne，最小特征 30% |
| 内部填充 | 闪电（Lightning）：只在需要撑住上方表面的地方填充，内部大多空心（实测熊：22 小时 12 分 → 约 16 小时） |
| 线宽 | 0.2 喷嘴改 0.2，其他喷嘴沿用 U1 默认 |
| 冷却 | 风扇 100%，首层除外 |
| 回抽抬升 | U1 默认已开启，不另外改 |

**手办＋熨烫**：再加熨烫“所有朝上的平面”（例如平的底座顶部），熨烫间距为喷嘴的 25%（0.4 喷嘴＝0.1 mm）。手办身上朝上的小平台也会被烫到，请在切片预览确认细节。

**一定要自己做的事**（文件无法设置）：在 Orca 把模型**往后倾 20–45°**（需要时再往左或右 20°），减少悬空面，支撑痕迹会少很多。

> **为什么是 Tree Hybrid**：原帖的重点之一是在树状支撑**内部加填充**，避免支撑中途断掉。U1 默认的树状样式是 Organic，Organic 的树干一律空心、会忽略填充设置；改成 Tree Hybrid 才会填充（实测同一只熊：Organic 每根支撑只有一圈外壳，Tree Hybrid 内部有间距 1.2 mm 的填充线）。代价是用料约多 3%、打印时间约多 2%；大片平坦的悬空面底下会改用普通支撑，那里比较难拆。

## 11. 转换为 Snapmaker U1

别人分享的 3MF 常是 Bambu Lab 等其他机型的项目，直接打开会沿用原机型盘面，物体可能超出 U1。

- 这类文件的卡片与详情面板会出现 **非 U1** 警示（含原机型），左侧“非 U1”可列出全部。
- 点详情面板的 **转换为 Snapmaker U1**：另存为 `<原名>-U1.3mf` 并导入模型库，原文件不动。转换内容：
  - 机型、process、耗材改用 U1 预设，**按设置页的喷嘴尺寸**选择；原文件喷嘴不同时，报告会列出“喷嘴：按设置 X mm（原文件 Y mm）”。
  - 兼容性修正：启用 Exclude Object、关闭 Brim、可变层高时把树状支撑改为 Hybrid。
  - 多盘物体移到 U1 盘面坐标；无法安全换算的盘保持原位并说明原因。
  - 保留原文件的耗材流速、温度、冷却设置。
- 同一个文件再转一次会先询问，避免产生 `-U1-2`。
- 很大的项目（模型数据超过 1 GB）也能转换，只是比较久。

## 12. 重复、丢失与回收站

- **重复**（左侧栏）：列出模型库中内容完全相同的文件，按组显示“重复组 N”徽章。由你决定删哪一个，App 不会自动删除。旧文件的指纹在启动后于后台建立；尚未下载到本机的 iCloud 文件会先跳过，下载后才比对。
- **丢失**：记录还在、但目前根目录找不到文件（例如换了根目录或手动移走）。
  - 单个：详情面板“重新定位…”指到文件现在的位置。
  - 多个：“按文件名找回…”在根目录（含子文件夹）找同名文件，确认后一次应用，不移动文件。
  - 不要了：勾选后“移除所选…”只移除记录，不删任何文件。
- **回收站**：删除的文件在 `<根目录>/.trash/`，可逐个“还原”回原位；“清空回收站…”需二次确认后才真的删除。
- **重建索引**：若有文件在模型库文件夹里却不在索引中（例如手动放入），上方会提示，点“重建索引”即可收录。

## 13. 设置页

| 项目 | 说明 |
|---|---|
| 喷嘴尺寸 | 0.2／0.4／0.6／0.8 mm，影响转换 U1 与导出的预设 |
| 语言 | English／繁體中文／简体中文，默认跟随系统 |
| 模型库根目录 | 更改时**不移动任何文件**，只对新根目录重建索引；旧根目录的记录标为“丢失”，切回即恢复 |
| 料卷颜色 | 1–4 卷的实际色号；“恢复理想 CMYK”回到默认 |
| 耗材库 | 见[第 8 节](#8-耗材库与采购建议) |
| 版本与更新 | 当前版本、打开 Releases 页面、自动检查更新开关 |

**更新**：默认在后台每 24 小时最多查一次 GitHub 上的最新版，有新版时在侧栏提示（前往下载／跳过此版本／关闭）。这是 App 唯一的网络行为，可在这里关闭。更新一律手动下载安装。

## 14. 常见问题

**导出的文件在 Orca 打开后，手办设置没有生效？**
请确认用的是新版 3mfDeck（1.2610.110033 以后）。旧版写入的设置会被 Orca 忽略。

**为什么导入时某个文件没有被收进来？**
看提示：内容和模型库中某个文件完全相同时会跳过（原文件留在原处）；不支持的格式也会跳过。

**“需买耗材”的颜色一定要买吗？**
不一定。旁边会写“不买则用某槽（ΔE）”，你可以接受色差直接打印。

**换了根目录，所有文件都变成“丢失”？**
换根目录不会移动文件，原根目录下的记录会标为丢失。切回原根目录即恢复；或用“按文件名找回…”对应到新位置。

**转换 U1 或手办设置说找不到 Snapmaker Orca？**
这两个功能需要读取本机 Snapmaker Orca 的预设文件，请先安装 Snapmaker Orca。
